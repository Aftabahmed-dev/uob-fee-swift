# UoB Smart Pay

Build a modern, responsive, single-page website prototype for the University of Balochistan named "UoB Smart Fee Portal".

IMPORTANT:

This is a frontend-only UI/UX prototype. Do NOT create any backend, authentication, database, or real payment gateway. Simulate the payment process with beautiful UI components only.

Objective:

The University of Balochistan currently has only one bank counter where thousands of students wait in long queues for hours to submit semester fees. This portal aims to reduce waiting time by allowing students to complete the fee submission process online through supported banks and digital wallets.

Target Users:

University of Balochistan students.
